# Guides

Task-shaped help for running `eshu-webhook`. Pick the job
you're doing:

| Guide | Use it when |
|---|---|
| [Operate](operate.md) | You're running the image and watching health, metrics, and logs |
| [Troubleshoot](troubleshoot.md) | Deliveries are failing and you need the `reason` field decoded |
| [Provider setup](seed.md) | You're pointing a provider at this service (there is no seed step) |
| [Release](release.md) | You're publishing an image or changing the intake wire version |

For the ideas behind these guides, see [concepts](../concepts/README.md).
For every setting, see [reference](../reference/README.md).
